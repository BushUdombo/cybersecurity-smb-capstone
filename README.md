# Cybersecurity SMB Capstone Project

## Overview

This project presents a comprehensive cybersecurity framework for a simulated small business (SMB). It follows the NIST Cybersecurity Framework (CSF) and adopts a risk-based approach to protecting critical business assets from cyber threats such as ransomware, phishing, malware, insider threats, and data breaches.

The project demonstrates how governance, risk management, security controls, incident response, and disaster recovery can be integrated into a practical cybersecurity program suitable for small and medium-sized organizations.

---

## Objectives

- Identify organizational assets and cybersecurity risks.
- Implement security controls based on industry best practices.
- Improve the organization's ability to detect cyber threats.
- Develop an incident response strategy.
- Ensure business continuity through disaster recovery planning.

---

## Framework Used

**NIST Cybersecurity Framework (CSF)**

- Identify
- Protect
- Detect
